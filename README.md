# Sana Burney — portfolio

Artist portfolio for [Sana Burney](https://www.sanaburney.com), built with Angular 21.

## Local development

Requires Node.js 22.

```bash
npm install
npm start
```

Then open http://localhost:8080/.

## Production build

```bash
npm run build
```

Static files are written to `dist/`, which is the Cloudflare Pages output directory.
